# 🎨 Graphic Designer Web

A modern, responsive **portfolio website** for a graphic designer. Pure HTML, CSS and a little JavaScript. No build step.

## Pages
- `index.html` – Home
- `about.html` – About
- `services.html` – Services, process and FAQ
- `portfolio.html` – Projects with filter buttons
- `contact.html` – Contact form (opens the visitor's email app)
- `404.html` – Page not found

## Customize
- Brand colors: `:root` variables at the top of `css/style.css`
- Email address: replace `hello@designer.com` in every page (search the project)
- Portfolio: replace the SVG files in `images/` with your real work
- SEO: each page has its own `<title>` and `<meta name="description">`
- `sitemap.xml` and `robots.txt`: change the web address to your real domain

## Run
```bash
git clone https://github.com/SaadDev-Online/Graphic-Designer-Web.git
```
Open `index.html` in your browser.
