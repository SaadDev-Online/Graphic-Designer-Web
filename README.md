# CreaStudio - Graphic Designer Website

A bright, multi-page portfolio website. Plain HTML, CSS and JavaScript. No build step and no outside libraries.

## Pages
`index.html` Home, `about.html` About, `services.html` Services and FAQ, `portfolio.html` Design concepts, `contact.html` Contact form, `404.html` Not found.

## Things to update
- **Email:** `hello@designer.com` appears on every page and in `contact.html` (`data-email`). Replace it with your real email.
- **Portfolio:** the six images in `images/c*.svg` are sample concepts. Replace them with real work when you have it.
- **Domain:** `sitemap.xml` and `robots.txt` use the GitHub Pages address. Change it if your address is different.
- **Contact form:** it opens the visitor's email app. A real form service would need an account and keys.
- **Colors and fonts:** see the `:root` variables at the top of `css/style.css`. Fonts are in `fonts/`.
